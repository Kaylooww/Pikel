# ADR-002 — Server authoritative competitive play

**Status:** accepted on 2026-11-17, when the project owner asked for RP-030 to RP-033 to be built; first LAN slice implemented (see `docs/06_NETWORKING.md`). **Decision:** Godot headless match server is the only authority for player legal movement, ball contacts, faults, scoring and match lifecycle. Clients transmit sequenced inputs and can predict local visuals; snapshots repair divergence. **Alternatives rejected:** client-hosted ball truth without validation (easy to cheat/desync); indiscriminate Node3D transform RPCs (insufficient game-event coherence). **Consequence:** more engineering and hosting cost, but consistent competition. **Implemented so far:** one LAN singles match per server process. Internet deployment, reconnect, doubles and matchmaking are not.
