# Reference assets

The `concept_art/` PNGs were generated specifically for this project, then split from a 2×2 art-direction board into four individual images. They are **not** captured from *just volleyball*, are not existing third-party game assets, and are not production-ready meshes or texture atlases.

The `technical/` diagrams are original vector illustrations produced for this development pack. Numeric dimensions should always be checked against the official sport rulebook. Source `.svg` and viewable `.png` are provided.

Don't delete the `references/` directory from your **development repository**. You can exclude it from final shipped game builds if it's only documentation art.
