# Package manifest

This source archive includes a Godot 4.7.2 project, placeholder scenes/scripts for a local training vertical slice, extensive Markdown specifications, integration instructions and original reference images.

## Top-level entry points

- `project.godot` — import directly through Godot Project Manager.
- `README.md` and `START_HERE.md` — quickest start.
- `SETUP_WINDOWS_GODOT_CLAUDE.md` — detailed Windows setup + Claude Code + optional Godot MCP.
- `prompts/MASTER_STARTING_PROMPT.md` — copy into Claude Code from project root.
- `CLAUDE.md`, `AGENTS.md` — project agent policy.
- `docs/` — full game, architecture, rule, physics, network, UI, art, QA, roadmap, security and release specs.
- `references/concept_art/` — five original generated PNG concept reference images.
- `references/technical/` — court, targeting, networking and palette diagrams in SVG + PNG.
- `scenes/`, `scripts/`, `assets/`, `tests/`, `tools/` — actual Godot files and source structure.

## Explicitly not bundled

Godot engine executable, Claude Code CLI, third-party MCP add-ons, paid assets, final Blender models, production networking/backend, export templates or account credentials. Use the included installation guide to obtain the software from its respective vendor.
